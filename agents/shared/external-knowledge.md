## External Knowledge

Follow the tooling hierarchy (specs > codebase > Context7 MCP > web research). Use the project's configured platform CLI (check `platform` in `.agents/hatch.json`):
- **GitHub:** `gh` CLI
- **Azure DevOps:** `az devops` / `az boards` / `az repos` CLI
- **GitLab:** `glab` CLI
